3MF Fixer for 3D Builder

Makes 3MF files saved by slicers such as Bambu Studio open in Microsoft 3D Builder again. Your file stays on your device. Source on GitHub

Why can't 3D Builder open the file?

Some slicers, such as Bambu Studio and slicers based on it (for example OrcaSlicer), save each object's mesh as a separate file inside the 3MF package and link to it from the main model. 3D Builder can't follow those links and shows “Couldn't load that. Error code: 0x80004005”. These slicers also drop the colours you set in 3D Builder.

What does the fix change?
  • All linked meshes are merged into one model. Every part keeps its shape, position and name.
  • Colours stored in the file are kept, including the slicer's filament colours and painted areas. Painted triangles get the colour that covers most of them.
  • If the colours were lost, you choose: a different random colour per part, or one colour for everything.
  • Slicer settings, plates and slicer thumbnails are removed. A small preview picture is stored instead, so the fixed file is usually smaller than the original.
